## Feature: File & Artifact Management System

### Overview
A centralized repository for all agent-generated outputs (reports, code, datasets, images, charts, etc.). Users can browse by session/project/date, search, preview common formats inline, download files (single or bulk as a ZIP), track versions, and share via time-limited links. Files are stored in Supabase Storage with metadata and versioning in Postgres via Drizzle ORM. Secure, signed URLs are used for previews/downloads. Retention and quotas are enforced by user tier.

### User Stories & Requirements
- As an authenticated user, I want to browse files generated by my agent runs (by session/project/date) so that I can quickly find relevant artifacts.
  - Acceptance:
    - Files visible only to the owning user/team (RLS via server actions).
    - Filters by sessionId, projectId, type, date range.
    - List and grid views.
- As a user, I want to search artifacts by filename and type so that I can locate items quickly.
  - Acceptance:
    - Search by name (case-insensitive, partial match) and filter by MIME/type.
    - Results return within 500ms for <5k artifacts.
- As a user, I want to preview common formats inline (PDF, images, CSV, JSON, Markdown) so that I don’t need to download files.
  - Acceptance:
    - PDF renders inline with pagination.
    - Image renders inline.
    - CSV renders as table (first 5k rows or 10MB max preview).
    - JSON/Markdown rendered with formatting.
    - Unsupported types show a download-only state.
- As a user, I want artifact version history so that I can view previous iterations.
  - Acceptance:
    - Each artifact shows a version list with timestamps, size, and MIME.
    - The latest version is clearly marked and can be previewed/downloaded.
- As a user, I want to download individual files or bulk download multiple files as a ZIP.
  - Acceptance:
    - Single download via signed URL valid for 60–300 seconds.
    - Bulk ZIP download for up to 100 files or 500MB total per request.
- As a user, I want to share an artifact (or version) via a time-limited link so that collaborators can access it without an account.
  - Acceptance:
    - Create share link with expiration (hours/days).
    - Recipients can view/download only that artifact/version.
    - Owner can revoke links at any time.
- As a user, I want storage quotas enforced with upgrade prompts so that I understand limits.
  - Acceptance:
    - Uploads blocked when quota exceeded; UI shows remaining quota.
    - Tier-based quotas and retention (Free: 30 days, Pro: 90 days) with cleanup cron job.
- As a user, I want reliable uploads with progress and failure retry so that large files complete successfully.
  - Acceptance:
    - Client performs direct upload via signed upload URL.
    - On failure, user can retry; partial uploads are cleaned up.

```typescript
'use server';

import { db } from '@/db';
import { artifacts, artifactVersions, storageUsage, artifactShares } from '@/db/schema/artifacts';
import { eq, and, ilike, desc, sql as dsql, inArray } from 'drizzle-orm';
import { requireUserId } from '@/lib/auth';
import { supabaseAdmin, ARTIFACTS_BUCKET } from '@/lib/supabase/server';
import { getQuotaBytesForTier, getRetentionDaysForTier, getUserTier } from '@/lib/tiers';
import crypto from 'crypto';
import { randomBytes } from 'crypto';

export type ListArtifactsInput = {
  projectId?: string;
  sessionId?: string;
  q?: string;
  type?: string; // mime or kind
  view?: 'list' | 'grid';
  limit?: number;
  offset?: number;
  sort?: 'createdAt' | 'updatedAt' | 'name';
  order?: 'asc' | 'desc';
};

export async function listArtifacts(input: ListArtifactsInput = {}) {
  const userId = await requireUserId();
  const { projectId, sessionId, q, type, limit = 50, offset = 0, sort = 'updatedAt', order = 'desc' } = input;

  const where = [
    eq(artifacts.userId, userId),
    projectId ? eq(artifacts.projectId, projectId) : undefined,
    sessionId ? eq(artifacts.sessionId, sessionId) : undefined,
    q ? ilike(artifacts.name, `%${q}%`) : undefined,
  ].filter(Boolean) as any[];

  const rows = await db.query.artifacts.findMany({
    where: where.length ? and(...where) : undefined,
    orderBy: (fields, { asc, desc }) => {
      const dir = order === 'asc' ? asc : desc;
      if (sort === 'name') return dir(fields.name);
      if (sort === 'createdAt') return dir(fields.createdAt);
      return dir(fields.updatedAt);
    },
    with: {
      // Optionally join currentVersion
    },
    limit,
    offset,
  });

  // Count total (optional)
  const [{ count }] = await db.execute<{ count: number }>(
    dsql`select count(*)::int as count from artifacts where user_id = ${userId}`
  );

  return { items: rows, total: count };
}

export type RequestUploadInput = {
  artifactId?: string;
  name: string;
  projectId?: string;
  sessionId?: string;
  mimeType: string;
  size: number;
  checksumSha256?: string;
  kind?: string;
};

export async function requestUploadUrl(input: RequestUploadInput) {
  const userId = await requireUserId();
  const tier = await getUserTier(userId);
  const quota = getQuotaBytesForTier(tier);

  // Get user current usage
  const usage = await db.query.storageUsage.findFirst({ where: eq(storageUsage.userId, userId) });
  const used = BigInt(usage?.bytesUsed ?? 0);
  if (used + BigInt(input.size) > quota) {
    throw new Error('QUOTA_EXCEEDED');
  }

  // Ensure artifact exists or create it
  let artifactId = input.artifactId;
  if (!artifactId) {
    const [a] = await db.insert(artifacts).values({
      userId,
      name: input.name,
      kind: input.kind ?? 'file',
      projectId: input.projectId ? input.projectId as any : null,
      sessionId: input.sessionId ? input.sessionId as any : null,
    }).returning({ id: artifacts.id });
    artifactId = a.id;
  }

  // Determine next version
  const [{ max }] = await db.execute<{ max: number }>(
    dsql`select coalesce(max(version), 0) as max from artifact_versions where artifact_id = ${artifactId}`
  );
  const nextVersion = (max ?? 0) + 1;

  const ext = input.name.includes('.') ? input.name.split('.').pop() : undefined;
  const path = `${userId}/${artifactId}/v${nextVersion}/${crypto.randomUUID()}${ext ? '.' + ext : ''}`;

  // Create signed upload URL
  const { data, error } = await supabaseAdmin
    .storage
    .from(ARTIFACTS_BUCKET)
    .createSignedUploadUrl(path);
  if (error) throw new Error(`UPLOAD_URL_ERROR:${error.message}`);

  return {
    artifactId,
    version: nextVersion,
    uploadUrl: data.signedUrl,
    path,
    token: data.token, // if needed for client SDK
  };
}

export type FinalizeUploadInput = {
  artifactId: string;
  version: number;
  path: string;
  fileName: string;
  mimeType: string;
  size: number;
  checksumSha256?: string;
  createdBy?: 'user' | 'agent';
};

export async function finalizeUpload(input: FinalizeUploadInput) {
  const userId = await requireUserId();

  // Optional: HEAD to verify object exists
  const { data: head, error: headErr } = await supabaseAdmin.storage.from(ARTIFACTS_BUCKET).list(input.path.split('/').slice(0, -1).join('/'), {
    search: input.path.split('/').pop(),
  });
  if (headErr) {
    // Continue but log – listing can be flaky; download will fail if missing
    console.error('STORAGE_LIST_ERROR', headErr.message);
  }

  const previewable = isPreviewable(input.mimeType);
  const ext = input.fileName.includes('.') ? input.fileName.split('.').pop() : '';

  const [version] = await db.insert(artifactVersions).values({
    artifactId: input.artifactId as any,
    version: input.version,
    storagePath: input.path,
    fileName: input.fileName,
    mimeType: input.mimeType,
    size: input.size,
    extension: ext,
    checksumSha256: input.checksumSha256 ?? null,
    previewable,
    createdBy: input.createdBy ?? 'user',
  }).returning({ id: artifactVersions.id });

  // Update artifact's current version pointer and updatedAt
  await db.update(artifacts)
    .set({ currentVersionId: version.id, updatedAt: new Date() })
    .where(eq(artifacts.id, input.artifactId as any));

  // Update storage usage
  await db
    .insert(storageUsage)
    .values({ userId, bytesUsed: input.size, updatedAt: new Date() })
    .onConflictDoUpdate({
      target: storageUsage.userId,
      set: { bytesUsed: dsql`${storageUsage.bytesUsed} + ${input.size}`, updatedAt: new Date() },
    });

  return { versionId: version.id };
}

function isPreviewable(mime: string) {
  return [
    'application/pdf',
    'text/plain',
    'text/markdown',
    'application/json',
    'text/csv',
    'image/png',
    'image/jpeg',
    'image/gif',
    'image/webp',
    'image/svg+xml',
  ].some((m) => mime.includes(m));
}

export async function listVersions(artifactId: string) {
  const userId = await requireUserId();
  // Authorization: ensure artifact belongs to user
  const a = await db.query.artifacts.findFirst({ where: and(eq(artifacts.id, artifactId as any), eq(artifacts.userId, userId)) });
  if (!a) throw new Error('NOT_FOUND');

  const versions = await db.query.artifactVersions.findMany({
    where: eq(artifactVersions.artifactId, artifactId as any),
    orderBy: desc(artifactVersions.version),
  });
  return versions;
}

export async function getSignedDownloadUrl(versionId: string, opts?: { ttlSeconds?: number }) {
  const userId = await requireUserId();

  const v = await db.query.artifactVersions.findFirst({
    where: eq(artifactVersions.id, versionId as any),
    with: { },
  });
  if (!v) throw new Error('NOT_FOUND');

  const a = await db.query.artifacts.findFirst({
    where: and(eq(artifacts.id, v.artifactId as any), eq(artifacts.userId, userId)),
  });
  if (!a) throw new Error('FORBIDDEN');

  const ttl = Math.min(Math.max(opts?.ttlSeconds ?? 120, 30), 600);
  const { data, error } = await supabaseAdmin.storage.from(ARTIFACTS_BUCKET).createSignedUrl(v.storagePath, ttl);
  if (error) throw new Error(`SIGNED_URL_ERROR:${error.message}`);

  // Update last accessed
  await db.update(artifactVersions).set({ lastAccessedAt: new Date() }).where(eq(artifactVersions.id, versionId as any));

  return { url: data.signedUrl, mimeType: v.mimeType, fileName: v.fileName, size: v.size };
}

export async function deleteVersion(versionId: string) {
  const userId = await requireUserId();
  const v = await db.query.artifactVersions.findFirst({ where: eq(artifactVersions.id, versionId as any) });
  if (!v) throw new Error('NOT_FOUND');

  const a = await db.query.artifacts.findFirst({
    where: and(eq(artifacts.id, v.artifactId as any), eq(artifacts.userId, userId)),
  });
  if (!a) throw new Error('FORBIDDEN');

  // Delete object in storage
  const { error } = await supabaseAdmin.storage.from(ARTIFACTS_BUCKET).remove([v.storagePath]);
  if (error) throw new Error(`STORAGE_DELETE_ERROR:${error.message}`);

  // Update usage
  await db.insert(storageUsage).values({ userId, bytesUsed: 0 })
    .onConflictDoUpdate({
      target: storageUsage.userId,
      set: { bytesUsed: dsql`${storageUsage.bytesUsed} - ${v.size}`, updatedAt: new Date() },
    });

  // Delete row
  await db.delete(artifactVersions).where(eq(artifactVersions.id, versionId as any));

  // If deleted was currentVersion, update artifact pointer
  const current = await db.query.artifacts.findFirst({ where: eq(artifacts.id, v.artifactId as any) });
  if (current?.currentVersionId === versionId) {
    const latest = await db.query.artifactVersions.findFirst({
      where: eq(artifactVersions.artifactId, v.artifactId as any),
      orderBy: desc(artifactVersions.version),
    });
    await db.update(artifacts).set({ currentVersionId: latest?.id ?? null, updatedAt: new Date() }).where(eq(artifacts.id, v.artifactId as any));
  }

  return { ok: true };
}

export async function createShareLink(input: { artifactId?: string; versionId?: string; expiresInHours: number; allowDownload?: boolean; }) {
  const userId = await requireUserId();
  if (!input.artifactId && !input.versionId) throw new Error('INVALID_INPUT');

  // Authorization: check ownership if artifactId provided; if versionId provided, check via artifactId
  if (input.artifactId) {
    const a = await db.query.artifacts.findFirst({ where: and(eq(artifacts.id, input.artifactId as any), eq(artifacts.userId, userId)) });
    if (!a) throw new Error('FORBIDDEN');
  }
  if (input.versionId) {
    const v = await db.query.artifactVersions.findFirst({ where: eq(artifactVersions.id, input.versionId as any) });
    if (!v) throw new Error('NOT_FOUND');
    const a = await db.query.artifacts.findFirst({ where: and(eq(artifacts.id, v.artifactId as any), eq(artifacts.userId, userId)) });
    if (!a) throw new Error('FORBIDDEN');
  }

  const token = randomBytes(24).toString('base64url');
  const expiresAt = new Date(Date.now() + Math.min(Math.max(input.expiresInHours, 1), 720) * 3600 * 1000);

  const [share] = await db.insert(artifactShares).values({
    token,
    userId,
    artifactId: input.artifactId ? (input.artifactId as any) : null,
    versionId: input.versionId ? (input.versionId as any) : null,
    allowDownload: input.allowDownload ?? true,
    expiresAt,
  }).returning();

  return { url: `${process.env.NEXT_PUBLIC_APP_URL}/share/${token}`, expiresAt: share.expiresAt };
}

export async function revokeShareLink(token: string) {
  const userId = await requireUserId();
  const share = await db.query.artifactShares.findFirst({ where: and(eq(artifactShares.token, token), eq(artifactShares.userId, userId)) });
  if (!share) throw new Error('NOT_FOUND');

  await db.update(artifactShares).set({ revokedAt: new Date() }).where(eq(artifactShares.id, share.id));
  return { ok: true };
}
```

```typescript
// /app/api/share/route.ts (resolve share token - optional for server components)
import { NextRequest, NextResponse } from 'next/server';
import { db } from '@/db';
import { artifactShares, artifactVersions, artifacts } from '@/db/schema/artifacts';
import { and, eq } from 'drizzle-orm';
import { supabaseAdmin, ARTIFACTS_BUCKET } from '@/lib/supabase/server';

export async function GET(req: NextRequest) {
  const token = req.nextUrl.searchParams.get('token');
  if (!token) return NextResponse.json({ error: 'INVALID' }, { status: 400 });

  const share = await db.query.artifactShares.findFirst({ where: eq(artifactShares.token, token) });
  if (!share || share.revokedAt || new Date(share.expiresAt) < new Date()) {
    return NextResponse.json({ error: 'EXPIRED' }, { status: 410 });
  }

  // Determine versions accessible
  let versions: any[] = [];
  if (share.versionId) {
    const v = await db.query.artifactVersions.findFirst({ where: eq(artifactVersions.id, share.versionId as any) });
    if (!v) return NextResponse.json({ error: 'NOT_FOUND' }, { status: 404 });
    versions = [v];
  } else if (share.artifactId) {
    versions = await db.query.artifactVersions.findMany({ where: eq(artifactVersions.artifactId, share.artifactId as any) });
  }

  return NextResponse.json({
    artifactId: share.artifactId,
    versionId: share.versionId,
    allowDownload: share.allowDownload,
    versions: versions.map(v => ({ id: v.id, fileName: v.fileName, mimeType: v.mimeType, size: v.size })),
  });
}
```

```typescript
// /app/api/artifacts/bulk-download/route.ts
// Node runtime; streams a ZIP of provided version IDs (auth or share token)
import { NextRequest } from 'next/server';
import { db } from '@/db';
import { artifactVersions, artifacts, artifactShares } from '@/db/schema/artifacts';
import { supabaseAdmin, ARTIFACTS_BUCKET } from '@/lib/supabase/server';
import { and, eq, inArray } from 'drizzle-orm';
import JSZip from 'jszip';

export const runtime = 'nodejs';

export async function POST(req: NextRequest) {
  const body = await req.json().catch(() => ({}));
  const versionIds: string[] = body.versionIds ?? [];
  const shareToken: string | undefined = body.shareToken;

  if (!Array.isArray(versionIds) || versionIds.length === 0 || versionIds.length > 100) {
    return new Response(JSON.stringify({ error: 'INVALID_IDS' }), { status: 400 });
  }

  // Auth: either user session via middleware or share token
  let authorizedArtifactIds: Set<string> = new Set();
  if (shareToken) {
    const share = await db.query.artifactShares.findFirst({ where: eq(artifactShares.token, shareToken) });
    if (!share || share.revokedAt || new Date(share.expiresAt) < new Date()) {
      return new Response(JSON.stringify({ error: 'EXPIRED' }), { status: 410 });
    }
    if (share.versionId && !versionIds.includes(share.versionId)) {
      return new Response(JSON.stringify({ error: 'FORBIDDEN' }), { status: 403 });
    }
    if (share.artifactId) authorizedArtifactIds.add(share.artifactId);
  } else {
    // Assume middleware attaches user id to request; otherwise convert to server action
    return new Response(JSON.stringify({ error: 'AUTH_REQUIRED' }), { status: 401 });
  }

  const versions = await db.query.artifactVersions.findMany({
    where: inArray(artifactVersions.id, versionIds as any),
  });

  // Enforce share scope if token
  if (shareToken) {
    if (authorizedArtifactIds.size) {
      for (const v of versions) {
        if (!authorizedArtifactIds.has(v.artifactId as any)) {
          return new Response(JSON.stringify({ error: 'FORBIDDEN' }), { status: 403 });
        }
      }
    }
  }

  const totalSize = versions.reduce((sum, v) => sum + Number(v.size), 0);
  if (totalSize > 500 * 1024 * 1024) {
    return new Response(JSON.stringify({ error: 'TOO_LARGE' }), { status: 413 });
  }

  const zip = new JSZip();

  // Fetch each file and add to zip
  for (const v of versions) {
    const { data, error } = await supabaseAdmin.storage.from(ARTIFACTS_BUCKET).createSignedUrl(v.storagePath, 300);
    if (error) return new Response(JSON.stringify({ error: 'SIGNED_URL_ERROR' }), { status: 500 });

    const fileRes = await fetch(data.signedUrl);
    if (!fileRes.ok) return new Response(JSON.stringify({ error: 'FETCH_ERROR' }), { status: 502 });
    const arrBuf = await fileRes.arrayBuffer();

    // Use fileName or path segment to avoid conflicts
    const baseName = v.fileName || v.storagePath.split('/').pop()!;
    zip.file(baseName, arrBuf);
  }

  const zipBuf = await zip.generateAsync({ type: 'nodebuffer', compression: 'DEFLATE' });

  return new Response(zipBuf, {
    status: 200,
    headers: {
      'Content-Type': 'application/zip',
      'Content-Disposition': `attachment; filename="artifacts-${Date.now()}.zip"`,
    },
  });
}
```

```typescript
// /app/api/cron/storage-retention/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { db } from '@/db';
import { artifacts, artifactVersions, storageUsage } from '@/db/schema/artifacts';
import { supabaseAdmin, ARTIFACTS_BUCKET } from '@/lib/supabase/server';
import { getUserTier, getRetentionDaysForTier } from '@/lib/tiers';
import { eq, and, lt } from 'drizzle-orm';

// Protect via Vercel cron secret header
export async function POST(req: NextRequest) {
  if (req.headers.get('x-cron-secret') !== process.env.CRON_SECRET) {
    return NextResponse.json({ error: 'UNAUTHORIZED' }, { status: 401 });
  }

  // Simple approach: scan in batches
  const batch = await db.query.artifactVersions.findMany({
    // we'll filter after fetching due to per-user retention
    limit: 1000,
  });

  let deleted = 0;
  for (const v of batch) {
    const a = await db.query.artifacts.findFirst({ where: eq(artifacts.id, v.artifactId as any) });
    if (!a || a.pinned) continue;
    const tier = await getUserTier(a.userId);
    const days = getRetentionDaysForTier(tier);
    const cutoff = Date.now() - days * 24 * 3600 * 1000;
    if (new Date(v.createdAt).getTime() < cutoff) {
      const { error } = await supabaseAdmin.storage.from(ARTIFACTS_BUCKET).remove([v.storagePath]);
      if (!error) {
        await db.delete(artifactVersions).where(eq(artifactVersions.id, v.id as any));
        await db.insert(storageUsage).values({ userId: a.userId, bytesUsed: 0 })
          .onConflictDoUpdate({
            target: storageUsage.userId,
            set: { bytesUsed: dsql`${storageUsage.bytesUsed} - ${v.size}`, updatedAt: new Date() },
          });
        deleted++;
      } else {
        console.error('RETENTION_DELETE_ERROR', v.id, error.message);
      }
    }
  }

  return NextResponse.json({ deleted });
}
```

### Edge Cases & Error Handling
- Quota exceeded:
  - requestUploadUrl throws QUOTA_EXCEEDED; UI shows upgrade CTA via Whop.
- Partial/failed upload:
  - finalizeUpload should verify object existence; if missing, return error and advise retry.
  - Consider cleanup of orphaned paths via background job if finalize not called within 24h.
- MIME spoofing:
  - Do not render HTML or executable content. For text/html, disable inline preview; force download.
  - For preview, set sandboxed iframe for PDFs and text renders; never use dangerouslySetInnerHTML.
- Large files:
  - Preview cap at 10MB or 5k rows for CSV. Show “Open externally” for larger files.
  - Bulk ZIP capped at 500MB and 100 files to avoid function timeouts.
- Share link misuse:
  - Expired or revoked tokens return 410.
  - Share links scoped to artifact or version; enforce allowDownload flag.
  - Rate limit share endpoint (via middleware) to prevent abuse.
- Race conditions:
  - currentVersionId updated after finalizeUpload; if concurrent uploads, version increment derived from DB query; acceptable risk; optionally lock with transaction.
- Retention:
  - Pinned artifacts are excluded from deletion.
  - Cron secured via header secret.
- Security:
  - Storage bucket is private; only signed URLs used.
  - All server actions validate ownership via Clerk userId.
  - Avoid exposing Supabase service keys to client.
- Performance:
  - List pagination; index on (user_id, name) and artifact_id for versions.
  - Use caching for signed URLs only minimally due to short TTL.
